# LeisureFlies Travels website

Built with Astro. Content lives in `src/data/` (destinations, visas, site details) and images in `public/img/`.

- `npm install` then `npm run dev` to preview locally
- `npm run build` creates the `dist/` folder
- Vercel: set Framework Preset to **Astro**. It builds automatically on every push.

Pages: home, /holidays (+ one page per destination), /visa (+ one page per country), /flights-hotels (Send the Screenshot rules), /cruises, /about, /contact, /legal.
